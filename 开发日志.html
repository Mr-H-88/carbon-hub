项目概述

数智碳路是一款面向生物质固废转化企业的碳管理数据看板应用，覆盖从原料入库到碳交易的全流程数据管理。核心模块包括：总览仪表盘、原料管理、热解制备、碳质分析、污染治理、碳汇核算、碳交易市场和 AI 智能优化。

技术栈

单文件 HTML（HTML + CSS + JS 全部内联）· ECharts 数据可视化 · localStorage 持久化 · Ardot 设计工具（画布设计稿 → 代码还原）

设计稿 → 应用代码还原

15:00 - 15:15

需求

将 Ardot 画布中的三屏首次启动体验设计稿生成可运行应用，严格还原设计稿中的布局结构、配色、圆角、间距等视觉细节。

还原要点

  • 配色系统：从 Ardot 节点 fill/stroke 值精确提取全部色值——主色 #0FBA82、辅色 #05B5D4、点缀 #F59E0A / #4F45E6，四层灰阶文本色，统一写入 CSS 变量
  • 三屏路由：欢迎页 → 配置向导（3 步表单动态渲染）→ 空状态仪表盘，通过 JS goToScreen() 切换
  • 配置向导：表单输入框聚焦态（绿色描边 + 浅蓝底）、下拉选择器、多选 chips（选中/未选中两种样式）、进度条填充动画
  • 空状态仪表盘：8 项侧边栏导航、青绿渐变欢迎 Banner、4 张空 KPI 卡（"—"值 + 模块引导提示）、减排趋势空状态、设备状态空状态、新手引导 4 步清单
  • 圆角/间距：卡片圆角 12-16px，按钮 8px，chips 16px（pill），表单输入 8px，间距严格按设计稿 itemSpacing 值还原
  • 阴影：CTA 按钮 0 8px 24px rgba(15,186,130,0.35)，表单卡片 0 4px 24px + 0 1px 3px 双层阴影，欢迎 Banner 0 8px 24px

    • 污染治理 → "配置治理设备 — 请先完成企业信息配置"
    • 碳汇核算 → "录入核算数据 — 需先完成热解批次和质检"

关键技术细节

CSS Design Tokens

/* 从 Ardot 设计稿提取的精确色值 */ :root { --c-primary: #0FBA82; /* 主色 绿 */ --c-cyan: #05B5D4; /* 辅色 青 */ --c-orange: #F59E0A; /* 点缀 橙 */ --c-purple: #4F45E6; /* 点缀 紫 */ --c-text-1: #1F2937; /* 主文本 */ --c-text-2: #6B7280; /* 次文本 */ --c-text-3: #9CA3AF; /* 辅助文本 */ --c-bg: #F5F7FA; /* 页面背景 */ --c-border: #E5E7EB; /* 边框 */ --radius-lg: 12px; /* 卡片圆角 */ --radius-xl: 16px; /* 大卡片圆角 */ --radius-md: 8px; /* 按钮圆角 */ }

Ardot 设计工具链

  • create_design → 创建新设计文件
  • search_style_guide → 搜索设计风格参考
  • build_style_guide → 构建设计系统 tokens
  • locate_available_space → 定位画布可用区域
  • batch_edit (I/U/C/M/D/G) → 批量编辑节点：插入、更新、复制、移动、删除、图片
  • batch_read → 批量读取节点属性（色值、圆角、间距、文字内容）
  • capture_screenshot → 截图验证设计效果
  • fetch_editor_state / fetch_file_info → 获取编辑器状态和文件信息

应用架构
